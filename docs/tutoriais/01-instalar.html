Em redes corporativas

Na Rede Sebrae, por exemplo: no Windows, clique com o botão direito no instalador e escolha Executar como administrador. Assim o programa fica instalado para todos os usuários do computador. A base é criada depois, na conta de quem vai operar o sistema. No Linux, o pacote .deb fica instalado para todos os usuários, e a instalação pede a senha de administrador.

Tutorial escrito, adaptado de roteiro para gravação. Os vídeos ainda estão em preparação. Use dados fictícios para testar e mantenha senhas e Termo fora de qualquer captura.

Objetivo

Preparar a gravação da instalação do Credenciamento e reconhecer a primeira tela do aplicativo.

Pré-requisitos

  1. Ter o pacote de instalação de teste fornecido pelo responsável. Registrar a versão do pacote usado na gravação.
  2. Usar um computador de treinamento. A interface informa uso exclusivo em uma máquina.
  3. Ter a instalação real disponível para completar as tomadas do instalador. Os nomes dos botões devem ser conferidos no pacote instalado.

Orientação para a gravação

Roteiro com tomada de instalação pendente de validação no pacote real. Não gravar botões presumidos como se estivessem conferidos. Os botões do assistente devem ser conferidos no pacote recebido.

Passo a passo e imagem

  1. [00:00–00:20] Mostrar o nome do pacote entregue pelo responsável, sem inventar endereço de download ou nome de arquivo.
  2. [00:20–01:10] Reservar a tomada da instalação no Windows. Registrar os botões exatamente como aparecerem no instalador entregue. Esta tomada aguarda conferência: o checkout contém configuração de empacotamento, mas não as telas do assistente.
  3. [01:10–01:35] Abrir o aplicativo instalado e mostrar o cabeçalho Credenciamento V208 · Beta 11. Se ele não corresponder ao pacote esperado, interromper a gravação e conferir a versão.
  4. [01:35–02:00] Clicar em Uso nesta versão. Ler a orientação de uso em uma máquina. Clicar em Entendi.
  5. [02:00–02:25] Mostrar Criar nova base. Se a criação já aparecer, mostrar Passo 1 de 4 — Nome e pasta. Deixar o preenchimento para o vídeo 02.
  6. [02:25–02:40] Para quem já tem base, mostrar Já tenho uma base quando disponível, Caminho da base e Continuar para o login. Apenas apresentar a alternativa.

Texto de narração

Leia as falas abaixo. Use o restante de cada intervalo para mostrar os campos, executar a ação e aguardar a resposta. Os tempos são uma proposta de edição.

00:00–00:20 — “Vamos preparar o Credenciamento. Use o pacote indicado pelo responsável. Confira a versão antes de começar.”

00:20–01:10 — “A instalação precisa ser mostrada no computador de treinamento. Acompanhe os nomes que aparecem no assistente do pacote entregue.”

01:10–01:35 — “Abra o aplicativo. Confira o nome e a versão no cabeçalho. Confira em Sobre a versão 208.11.3.”

01:35–02:00 — “Clique em Uso nesta versão. Leia a orientação. Esta edição trabalha em uma máquina. Clique em Entendi.”

02:00–02:25 — “Para começar do zero, use Criar nova base. Vamos fazer os quatro passos no próximo vídeo.”

02:25–02:40 — “Se já existe uma base, escolha a pasta dela. Confira o caminho antes de continuar para o login.”

Erros comuns e mensagem exibida

  1. Abrir uma edição diferente: conferir o cabeçalho Credenciamento V208 · Beta 11. Esse texto é identificação, não mensagem de erro.
  2. Esperar acesso simultâneo de vários computadores: o diálogo mostra “Esta versão é para uso exclusivo em uma máquina. Para uso multiusuário simultâneo, utilize a versão SaaS instalada em um servidor local.”
  3. Falha no instalador: a mensagem literal depende do pacote e do Windows. Não há mensagem nem botão de correção comprovados nos HTML. Capturar o aviso real e encaminhá-lo ao responsável.

Duração estimada

2 min 40 s. Estimativa editorial, incluindo leitura da tela, preenchimento e espera. Corte esperas longas; preserve os avisos e a confirmação final.
